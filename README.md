
#Task manager using SQLite and OOP
This is a simple command-line Task Manager application created using Python. The project allows users to manage their daily tasks by adding new tasks, viewing existing tasks, marking tasks as complete, and deleting tasks.

The application uses OOP principles through the Task and TaskManager classes. SQLite is used to store the tasks, allowing the data to remain available even after the program is closed.

The program provides a simple menu where users can choose to add, view, complete, or delete a task.

This project is part of Python programming coursework to demonstrate understnding of python, SQLite databases, and basic command-line applications.
